# 하준이의 책장 배포 안내 (v2)

`juni-app` 폴더를 복사해서 만든 새 버전입니다. 원본 `juni-app`은 지금 배포된 그대로 두고,
이 폴더에서만 언어 구분(한국어/영어/기타), 오늘 읽은 책 패널 수정, 통계 확장, 아이 이름 변경,
빠른 기록(이모지 선택 생략 가능) 기능을 추가했습니다. 실제로 쓰려면 이 폴더를 별도 Cloudflare
Pages 프로젝트로 새로 배포해야 합니다(기존 juni-app 배포와는 무관).

## 파일 구성
- `index.html` — 앱 전체 (홈 / 등록 / 책장 / 통계)
- `functions/api/lookup.js` — 책 정보 조회 프록시 (카카오 책 검색 API 사용)
- `manifest.json`, `icons/` — 홈 화면 추가 시 사용할 아이콘 설정

## ⚠️ 알라딘 API 관련 변경 안내
알라딘이 OpenAPI 서비스를 종료합니다 (신규 키 발급: 2026.9.4 종료 / 기존 키 서비스: 2026.10.30 종료).
그래서 책 정보 조회는 **카카오 책 검색 API**로 전환했습니다.

## 카카오 REST API 키 발급
1. https://developers.kakao.com 로그인 → 내 애플리케이션 → 애플리케이션 추가하기 (앱 이름 자유롭게)
2. 만든 앱 클릭 → 앱 키 → **REST API 키** 복사 (승인 대기 없이 바로 발급돼요)

## 배포 (Cloudflare Pages)
1. 이 폴더 전체를 GitHub 저장소에 올립니다.
2. Cloudflare Pages 프로젝트 → **Connect to Git** → 해당 저장소 선택 → 기본 설정으로 배포
3. 프로젝트 → Settings → **환경 변수(Environment variables)** 에서
   `KAKAO_REST_API_KEY` 이름으로 위에서 복사한 REST API 키를 등록
4. 재배포하면 `/api/lookup?isbn=...` 이 정상 동작합니다.

## 참고
- 카카오 책 검색 API는 무료이며 하루 호출 한도가 넉넉해 개인용으로 충분합니다.
- 바코드 스캔은 카메라 권한이 필요해 https 환경(Cloudflare Pages는 기본 https)에서만 동작합니다.

## 구글 시트 백업 연결 (선택)
데이터는 기본적으로 기기의 localStorage에 저장돼요. 아래 설정을 하면 등록/삭제할 때마다
구글 시트에도 같이 기록되고, 기기를 바꾸거나 저장소가 초기화됐을 때 시트에서 자동으로 복원돼요.
(단, 여러 기기를 동시에 쓰는 실시간 동기화는 아니에요 — 로컬 기록이 비어 있을 때만 시트에서 불러옵니다.)

1. 새 구글 스프레드시트를 만듭니다.
2. **확장 프로그램 → Apps Script** 를 열고, 이 저장소의 `backend/Code.gs` 내용을 전부 붙여넣습니다. (시트 컬럼: isbn, title, author, publisher, cover, link, date, emoji, note, ts, **language**)
3. **프로젝트 설정(톱니바퀴) → 스크립트 속성**에서 `WRITE_KEY` 이름으로 아무 긴 임의 문자열을 값으로 등록합니다.
4. **배포 → 새 배포 → 웹 앱** 선택 → 실행 계정: 나, 액세스 권한: 전체 공개(Anyone) → 배포.
5. 배포 후 나오는 `.../exec` 로 끝나는 URL을 복사합니다.
6. `index.html`에서 `var API_URL = '';` 와 `var WRITE_KEY = '';` 두 줄을 찾아
   각각 5번의 URL과 3번의 값으로 채운 뒤 재배포합니다.

⚠️ 이후 `Code.gs`를 수정할 때는 "새 배포"가 아니라 **배포 관리 → 수정 → 새 버전**으로 갱신하세요.
"새 배포"를 만들면 `/exec` 주소가 바뀌어 앱이 가리키던 주소가 끊깁니다.
